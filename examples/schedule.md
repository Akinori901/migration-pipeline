# 移行スケジュール

migration-loop が状態管理に使うファイル。**これが唯一の正**。
会話の記憶ではなく、常にこのファイルを読んで状態を復元する。

チェックボックスの意味:
- トリアージ … 原因タグの付与まで完了
- 対処 … 実装と検証まで完了

| ドメイン | トリアージ | 対処 | 備考 |
|---------|----------|------|------|
| orders  | [x]      | [x]  | 完了 |
| items   | [x]      | [ ]  | [パス変更] 2件をユーザー判断待ち |
| users   | [ ]      | [ ]  |      |
| reports | [ ]      | [ ]  |      |

## 判断待ちの内容

### items

- `[パス変更]` GET `/api/item/list` → `/api/items`
  フロントを新パスに合わせるか、新システム側にエイリアスを追加するか要判断
